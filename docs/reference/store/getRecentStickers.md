# store.getRecentStickers

Возвращает список идентификаторов недавно использованных стикеров.

<div class="vk-warning">
  <span>💡 Для вызова этого метода требуется авторизация пользователя.</span>
</div>

# Вызов метода

```csharp
List<int> recents = await api.Store.GetRecentStickersAsync();
```

</div>

<div class="vk-card">

# Параметры

Метод не принимает параметров.

</div>

<div class="vk-card">

# Результат

Возвращает `List<int>` со списком идентификаторов недавно отправленных стикеров.

</div>
