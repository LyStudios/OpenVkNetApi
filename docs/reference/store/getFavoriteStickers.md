# store.getFavoriteStickers

Возвращает список идентификаторов избранных стикеров текущего пользователя.

<div class="vk-warning">
  <span>💡 Для вызова этого метода требуется авторизация пользователя.</span>
</div>

# Вызов метода

```csharp
List<int> favorites = await api.Store.GetFavoriteStickersAsync();
```

</div>

<div class="vk-card">

# Параметры

Метод не принимает параметров.

</div>

<div class="vk-card">

# Результат

Возвращает `List<int>` со списком идентификаторов избранных стикеров.

</div>
