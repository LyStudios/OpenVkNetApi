# store.clearRecentStickers

Очищает список недавно использованных стикеров текущего пользователя.

<div class="vk-warning">
  <span>💡 Для вызова этого метода требуется авторизация пользователя.</span>
</div>

# Вызов метода

```csharp
bool ok = await api.Store.ClearRecentStickersAsync();
```

</div>

<div class="vk-card">

# Параметры

Метод не принимает параметров.

</div>

<div class="vk-card">

# Результат

Возвращает `bool` (`true` при успешной очистке списка).

</div>
