# Объект SearchHint (Поисковая подсказка)

Представляет отдельный элемент поисковой подсказки.

</div>

<div class="vk-card">

# Поля объекта

| Поле / Тип | Описание |
| :--- | :--- |
| **Type** <br> `string` | Тип подсказки (`"profile"`, `"group"`, `"app"`). |
| **Description** <br> `string` | Текстовое описание подсказки. |
| **Profile** <br> `User` | Профиль пользователя, если подсказка относится к профилю. |
| **Group** <br> `Group` | Объект сообщества, если подсказка относится к группе. |

</div>
