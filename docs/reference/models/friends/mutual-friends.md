# Объект MutualFriends (Общие друзья)

Возвращается при множественном запросе метода `friends.getMutual`.

</div>

<div class="vk-card">

# Поля объекта

| Поле / Тип | Описание |
| :--- | :--- |
| **Id** <br> `int` | Идентификатор целевого пользователя. |
| **CommonFriends** <br> `List<int>` | Список идентификаторов общих друзей. |
| **CommonCount** <br> `int` | Количество общих друзей. |

</div>
