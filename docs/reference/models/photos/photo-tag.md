# Объект PhotoTag (Отметка на фотографии)

Представляет отметку пользователя на фотографии.

</div>

<div class="vk-card">

# Поля объекта

| Поле / Тип | Описание |
| :--- | :--- |
| **Id** <br> `int` | Идентификатор отметки. |
| **UserId** <br> `int` | Идентификатор отмеченного пользователя. |
| **PlacerId** <br> `int` | Идентификатор пользователя, поставившего отметку. |
| **Date** <br> `long` | Дата добавления отметки в формате unixtime. |
| **X** <br> `double` | Координата левого верхнего угла (в процентах). |
| **Y** <br> `double` | Координата верхнего края (в процентах). |
| **X2** <br> `double` | Координата правого нижнего угла (в процентах). |
| **Y2** <br> `double` | Координата нижнего края (в процентах). |
| **Viewed** <br> `int` | Статус подтверждения (1 — подтверждена). |

</div>
