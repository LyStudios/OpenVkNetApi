# Объект City (Город)

Представляет собой город в географической базе OpenVK.

</div>

<div class="vk-card">

# Поля объекта

| Поле / Тип | Описание |
| :--- | :--- |
| **Id** <br> `int` | Идентификатор города. |
| **Title** <br> `string` | Название города. |
| **Area** <br> `string` | Район или область. |
| **Region** <br> `string` | Регион. |
| **Important** <br> `int` | Признак крупного города (`1` — крупный). |

</div>
