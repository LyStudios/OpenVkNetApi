# Объект Checkin (Чекин / Отметка)

Представляет гео-отметку пользователя в месте.

</div>

<div class="vk-card">

# Поля объекта

| Поле / Тип | Описание |
| :--- | :--- |
| **Id** <br> `int` | Идентификатор отметки. |
| **UserId** <br> `int` | Идентификатор пользователя, оставившего отметку. |
| **Date** <br> `long` | Время создания отметки (Unix timestamp). |
| **Latitude** <br> `double` | Географическая широта. |
| **Longitude** <br> `double` | Географическая долгота. |
| **PlaceId** <br> `int` | Идентификатор места. |
| **Text** <br> `string` | Текстовый комментарий к отметке. |
| **Distance** <br> `int` | Расстояние до точки в метрах (при поиске рядом). |

</div>
