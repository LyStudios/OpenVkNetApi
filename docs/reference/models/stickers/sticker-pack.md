# Объект StickerPack (Набор стикеров)

Представляет стикерпак в магазине стикеров OpenVK.

</div>

<div class="vk-card">

# Поля объекта

| Поле / Тип | Описание |
| :--- | :--- |
| **Id** <br> `int` | Идентификатор набора стикеров. |
| **Title** <br> `string` | Название набора. |
| **Description** <br> `string` | Описание набора. |
| **Author** <br> `string` | Автор стикерпака. |
| **Price** <br> `int` | Стоимость набора в голосах (`0` — бесплатный). |
| **Icon** <br> `string` | URL иконки набора. |
| **Previews** <br> `List<StickerImage>` | Превью изображений из набора. |
| **Stickers** <br> `List<Sticker>` | Список стикеров, входящих в набор. |
| **Purchased** <br> `bool` | Приобретен ли набор текущим пользователем. |
| **Active** <br> `bool` | Включен ли набор в интерфейсе сообщений. |

</div>
