# Объект Sticker (Стикер)

Представляет отдельный стикер из набора.

</div>

<div class="vk-card">

# Поля объекта

| Поле / Тип | Описание |
| :--- | :--- |
| **StickerId** <br> `int` | Идентификатор стикера. |
| **ProductId** <br> `int` | Идентификатор набора стикеров, к которому он принадлежит. |
| **Images** <br> `List<StickerImage>` | Изображения стикера в различных разрешениях без фона. |
| **ImagesWithBackground** <br> `List<StickerImage>` | Изображения стикера с фоном. |

</div>
