# Объект StickerImage (Изображение стикера)

Описывает вариант изображения стикера конкретного разрешения.

# Поля объекта

| Поле / Тип | Описание |
| :--- | :--- |
| **Url** <br> `string` | Прямая ссылка на изображение. |
| **Width** <br> `int` | Ширина в пикселях. |
| **Height** <br> `int` | Высота в пикселях. |
