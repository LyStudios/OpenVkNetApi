# Объект CallsHistory (История звонков)

Представляет историю звонков текущего пользователя.

</div>

<div class="vk-card">

# Поля объекта

| Поле / Тип | Описание |
| :--- | :--- |
| **Count** <br> `int` | Общее количество звонков в истории. |
| **Items** <br> `List<CallItem>` | Список объектов звонков с участниками, статусами и длительностью. |

</div>
