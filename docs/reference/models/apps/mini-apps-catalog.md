# Объект MiniAppsCatalog (Каталог мини-приложений)

Представляет каталог доступных мини-приложений платформы OpenVK.

</div>

<div class="vk-card">

# Поля объекта

| Поле / Тип | Описание |
| :--- | :--- |
| **Count** <br> `int` | Общее количество приложений в каталоге. |
| **Items** <br> `List<MiniAppItem>` | Список объектов приложений с названиями, иконками и URL запуска. |

</div>
