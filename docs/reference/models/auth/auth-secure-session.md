# Объект AuthSecureSession (Сессия авторизации)

Возвращается методом `auth.getSessionSecure`.

</div>

<div class="vk-card">

# Поля объекта

| Поле / Тип | Описание |
| :--- | :--- |
| **Token** <br> `string` | Токен доступа к сессии. |
| **Secret** <br> `string` | Секретный ключ подписи. |
| **UserId** <br> `int` | Идентификатор авторизованного пользователя. |
