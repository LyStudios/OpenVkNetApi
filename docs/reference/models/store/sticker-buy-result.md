# Объект StickerBuyResult (Результат покупки стикеров)

Возвращается методом `store.buy` после совершения покупки.

</div>

<div class="vk-card">

# Поля объекта

| Поле / Тип | Описание |
| :--- | :--- |
| **Success** <br> `int` | Код успешности операции (1 — успешно). |
| **ProductId** <br> `int` | Идентификатор купленного продукта. |
| **PackId** <br> `int` | Идентификатор приобретенного набора стикеров. |
