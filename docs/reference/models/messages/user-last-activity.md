# Объект UserLastActivity (Последняя активность пользователя)

Возвращается методом `messages.getLastActivity`.

</div>

<div class="vk-card">

# Поля объекта

| Поле / Тип | Описание |
| :--- | :--- |
| **Online** <br> `int` | Текущий онлайн-статус пользователя (`1` — в сети, `0` — оффлайн). |
| **Time** <br> `long` | Время последней активности (Unix timestamp). |
