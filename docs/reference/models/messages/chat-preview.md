# Объект ChatPreview (Предпросмотр беседы)

Описывает базовую информацию о беседе для предпросмотра перед вступлением.

</div>

<div class="vk-card">

# Поля объекта

| Поле / Тип | Описание |
| :--- | :--- |
| **AdminId** <br> `int` | Идентификатор создателя беседы. |
| **MembersCount** <br> `int` | Количество участников беседы. |
| **Title** <br> `string` | Название беседы. |
| **Photo** <br> `Photo` | Объект аватара беседы. |
| **Members** <br> `List<int>` | Идентификаторы первых участников беседы. |

</div>
