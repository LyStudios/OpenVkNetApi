# Объект HistoryAttachmentItem (Элемент вложений истории)

Представляет собой отдельное вложение из материалов переписки, возвращаемое методом `messages.getHistoryAttachments`.

</div>

<div class="vk-card">

# Поля объекта

| Поле / Тип | Описание |
| :--- | :--- |
| **MessageId** <br> `int` | Идентификатор сообщения, к которому прикреплено данное вложение. |
| **Attachment** <br> `Attachment` | Сам объект вложения (фотография, аудио, видео, документ и т.д.). |

</div>
