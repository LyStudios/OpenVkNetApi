# Объект ChatPreviewResponse (Ответ предпросмотра беседы)

Возвращается методом `messages.getChatPreview`.

</div>

<div class="vk-card">

# Поля объекта

| Поле / Тип | Описание |
| :--- | :--- |
| **Preview** <br> `ChatPreview` | Метаданные беседы (название, создатель, количество участников). |
| **Profiles** <br> `List<User>` | Профили участников беседы. |
| **Groups** <br> `List<Group>` | Профили участвующих сообществ. |
