# Объект ConversationMember (Участник беседы)

Описывает участника групповой беседы и его полномочия.

</div>

<div class="vk-card">

# Поля объекта

| Поле / Тип | Описание |
| :--- | :--- |
| **MemberId** <br> `int` | Идентификатор участника (пользователя или сообщества). |
| **InvitedBy** <br> `int` | Идентификатор пользователя, пригласившего данного участника. |
| **JoinDate** <br> `long` | Время вступления в беседу (Unix timestamp). |
| **IsAdmin** <br> `bool` | Является ли администратором беседы. |
| **IsOwner** <br> `bool` | Является ли создателем (владельцем) беседы. |
| **CanKick** <br> `bool` | Может ли текущий пользователь исключить этого участника. |

</div>
