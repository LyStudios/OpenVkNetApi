# Объект ChatModerators (Модераторы беседы)

Возвращается методом `messages.getChatModerators` и содержит список модераторов и создателя беседы.

</div>

<div class="vk-card">

# Поля объекта

| Поле / Тип | Описание |
| :--- | :--- |
| **OwnerId** <br> `int` | Идентификатор создателя (владельца) беседы. |
| **Moderators** <br> `List<int>` | Идентификаторы пользователей, назначенных модераторами беседы. |

</div>
