# Объект ChatSettings (Настройки беседы)

Содержит метаданные и настройки групповой беседы в объекте `Conversation`.

</div>

<div class="vk-card">

# Поля объекта

| Поле / Тип | Описание |
| :--- | :--- |
| **MembersCount** <br> `int` | Количество участников беседы. |
| **Title** <br> `string` | Название беседы. |
| **PinnedMessage** <br> `Message` | Закрепленное сообщение беседы. |
| **State** <br> `string` | Статус участия текущего пользователя (`"in"`, `"kicked"`, `"left"`). |
| **Photo** <br> `Photo` | Объект фотографии беседы. |
| **AdminId** <br> `int` | Идентификатор создателя/владельца беседы. |
| **ActiveIds** <br> `List<int>` | Идентификаторы наиболее активных участников. |
| **IsGroupChannel** <br> `bool` | Является ли беседа каналом сообщества. |

</div>
