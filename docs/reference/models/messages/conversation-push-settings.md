# Объект ConversationPushSettings (Настройки Push диалога)

Определяет индивидуальные параметры push-уведомлений для конкретного диалога или беседы.

</div>

<div class="vk-card">

# Поля объекта

| Поле / Тип | Описание |
| :--- | :--- |
| **DisabledUntil** <br> `int` | Время в секундах (Unix timestamp), до которого уведомления отключены (`-1` — навсегда, `0` — включены). |
| **DisabledForever** <br> `bool` | Отключены ли уведомления бессрочно. |
| **NoSound** <br> `bool` | Отключен ли звук уведомлений. |

</div>
