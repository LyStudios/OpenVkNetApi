# Объект Chat (Групповая беседа)

Представляет собой информацию о многопользовательской беседе.

</div>

<div class="vk-card">

# Поля объекта

| Поле / Тип | Описание |
| :--- | :--- |
| **Id** <br> `int` | Идентификатор беседы (`chat_id`). |
| **Type** <br> `string` | Тип диалога (`"chat"`). |
| **Title** <br> `string` | Название беседы. |
| **AdminId** <br> `int` | Идентификатор создателя (администратора) беседы. |
| **Users** <br> `List<int>` | Идентификаторы участников беседы. |
| **MembersCount** <br> `int` | Текущее количество участников. |
| **Photo50** <br> `string` | URL уменьшенного аватара беседы (50px). |
| **Photo100** <br> `string` | URL аватара беседы (100px). |
| **Photo200** <br> `string` | URL увеличенного аватара беседы (200px). |
| **Left** <br> `bool` | Покинул ли текущий пользователь беседу. |
| **Kicked** <br> `bool` | Был ли текущий пользователь исключен из беседы. |

</div>
