# Объект QueueSubscribeResult (Результат подписки на очередь)

Возвращается методом `queue.subscribe` для подключения к WebSocket/SSE сервису очередей.

</div>

<div class="vk-card">

# Поля объекта

| Поле / Тип | Описание |
| :--- | :--- |
| **Key** <br> `string` | Секретный ключ авторизации в сервисе очереди. |
| **Server** <br> `string` | URL сервера очереди. |
| **Ts** <br> `long` | Начальная временная метка (номер последовательности событий). |

</div>
