# account.getContactList

Возвращает список сохраненных контактов и номеров телефонов пользователя.

<div class="vk-warning">
  <span>💡 Для вызова этого метода требуется авторизация пользователя.</span>
</div>

# Вызов метода

```csharp
var contacts = await api.Account.GetContactListAsync();
```

</div>

<div class="vk-card">

# Параметры

Метод не принимает параметров.

</div>

<div class="vk-card">

# Результат

Возвращает `List<string>` со списком контактов.

</div>
