# account.getPrivacySettings

Возвращает дерево настроек приватности аккаунта текущего пользователя.

<div class="vk-warning">
  <span>💡 Для вызова этого метода требуется авторизация пользователя.</span>
</div>

# Вызов метода

```csharp
var privacy = await api.Account.GetPrivacySettingsAsync();
```

</div>

<div class="vk-card">

# Параметры

Метод не принимает параметров.

</div>

<div class="vk-card">

# Результат

Возвращает [AccountPrivacySettings](/reference/models/account/account-privacy-settings) со списком настроек приватности и доступных значений.

</div>
