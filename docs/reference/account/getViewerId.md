# account.getViewerId

Возвращает числовой идентификатор текущего авторизованного пользователя.

<div class="vk-warning">
  <span>💡 Для вызова этого метода требуется авторизация пользователя.</span>
</div>

# Вызов метода

```csharp
int userId = await api.Account.GetViewerIdAsync();
```

</div>

<div class="vk-card">

# Параметры

Метод не принимает параметров.

</div>

<div class="vk-card">

# Результат

Возвращает `int` — ID текущего пользователя.

</div>
