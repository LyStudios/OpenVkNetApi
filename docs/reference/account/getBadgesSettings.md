# account.getBadgesSettings

Возвращает настройки отображения значков (бейджей) и счетчиков на иконке приложения.

<div class="vk-warning">
  <span>💡 Для вызова этого метода требуется авторизация пользователя.</span>
</div>

# Вызов метода

```csharp
var badges = await api.Account.GetBadgesSettingsAsync();
```

</div>

<div class="vk-card">

# Параметры

Метод не принимает параметров.

</div>

<div class="vk-card">

# Результат

Возвращает [AccountBadgesSettings](/reference/models/account/account-badges-settings) со статусом отображения счетчиков.

</div>
