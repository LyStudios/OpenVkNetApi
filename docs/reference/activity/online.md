# activity.online

Отправляет сигнал активности (heartbeat) текущего пользователя или сессии для поддержания онлайн-статуса в OpenVK.

<div class="vk-warning">
  <span>💡 Для вызова этого метода требуется авторизация пользователя. Метод используется клиентами для периодического обновления статуса «в сети».</span>
</div>

# Вызов метода

```csharp
int result = await api.Activity.OnlineAsync();
```

</div>

<div class="vk-card">

# Параметры

Метод не принимает параметров.

</div>

<div class="vk-card">

# Результат

Возвращает `1` в случае успешной отправки сигнала онлайна.

</div>
