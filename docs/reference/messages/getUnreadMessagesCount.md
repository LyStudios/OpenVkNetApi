# messages.getUnreadMessagesCount

Возвращает общее количество непрочитанных входящих сообщений текущего пользователя.

# Вызов метода

```csharp
int unreadCount = await api.Messages.GetUnreadMessagesCountAsync();
```

</div>

<div class="vk-card">

# Параметры

Метод не принимает параметров.

</div>

<div class="vk-card">

# Результат

Возвращает `int` — суммарное число непрочитанных сообщений.
