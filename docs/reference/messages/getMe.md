# messages.getMe

Возвращает информацию о текущем пользователе в контексте системы сообщений OpenVK IM.

# Вызов метода

```csharp
User user = await api.Messages.GetMeAsync();
```

</div>

<div class="vk-card">

# Параметры

Метод не принимает параметров.

</div>

# Результат

Возвращает объект `User`, представляющий профиль текущего пользователя.
