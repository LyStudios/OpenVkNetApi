# messages.getUnreadConversationsCount

Возвращает количество диалогов с непрочитанными сообщениями.

# Вызов метода

```csharp
int count = await api.Messages.GetUnreadConversationsCountAsync();
```

</div>

<div class="vk-card">

# Параметры

Метод не принимает параметров.

</div>

<div class="vk-card">

# Результат

Возвращает `int` — число непрочитанных бесед/диалогов.
