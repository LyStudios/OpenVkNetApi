# messages.report

Отправляет жалобу на сообщение (спам, оскорбления и т.д.).

# Вызов метода

```csharp
int result = await api.Messages.ReportAsync(
    messageId: 1234,
    reason: 0
);
```

</div>

<div class="vk-card">

# Параметры

| Параметр / Тип | Описание |
| :--- | :--- |
| **messageId** <br> `int` | Идентификатор сообщения, на которое отправляется жалоба. <br> <span style="color: var(--vp-c-text-3)">целое число, обязательный параметр</span> |
| **reason** <br> `int?` | Причина жалобы (`0` — спам, `1` — детская порнография, `2` — экстремизм, `3` — насилие, `4` — пропаганда наркотиков, `5` — материал для взрослых, `6` — оскорбление). <br> <span style="color: var(--vp-c-text-3)">целое число</span> |

</div>

<div class="vk-card">

# Результат

Возвращает `1` в случае успешной отправки жалобы.

</div>
