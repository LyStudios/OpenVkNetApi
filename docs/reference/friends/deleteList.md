# friends.deleteList

Удаляет кастомный список друзей.

## Вызов метода

```csharp
int result = await api.Friends.DeleteListAsync(listId: 1);
```

</div>

<div class="vk-card">

# Параметры

| Параметр / Тип | Описание |
| :--- | :--- |
| **listId** <br> `int` | **Обязательный.** Идентификатор удаляемого списка друзей. |

</div>

<div class="vk-card">

# Результат

Возвращает `1` в случае успешного удаления.
