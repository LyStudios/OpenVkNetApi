# Места и география (Places)

Секция методов `places.*` предоставляет доступ к базе географических объектов (стран, городов) и чекинам пользователей.

## Доступные методы

| Метод | Описание |
| :--- | :--- |
| [places.getCheckins](./getCheckins.md) | Возвращает список чекинов в местах по координатам или пользователю. |
| [places.getCities](./getCities.md) | Возвращает список городов. |
| [places.getCountries](./getCountries.md) | Возвращает список стран. |
