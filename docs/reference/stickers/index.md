# Стикеры (Stickers)

Секция методов `stickers.*` предназначена для взаимодействия с магазином и наборами стикеров OpenVK.

## Доступные методы

| Метод | Описание |
| :--- | :--- |
| [stickers.get](./get.md) | Возвращает список доступных наборов стикеров или информацию о наборах. |
| [stickers.buy](./buy.md) | Позволяет приобрести или активировать набор стикеров. |
| [stickers.checkStock](./checkStock.md) | Проверяет наличие набора в магазине. |
