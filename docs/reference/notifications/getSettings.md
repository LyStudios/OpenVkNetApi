# notifications.getSettings

Возвращает настройки отображения и доставки уведомлений для текущего пользователя.

<div class="vk-warning">
  <span>💡 Для вызова этого метода требуется авторизация пользователя.</span>
</div>

# Вызов метода

```csharp
NotificationsSettings settings = await api.Notifications.GetSettingsAsync();
```

Метод не принимает параметров.
